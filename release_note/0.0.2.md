# Release v0.0.2

## New feature

- Change log format.  
- Add process time by stage.    
- Add suffix description to code and log for `--opt`, `--lop`, `--val`, and `--arg`. [ref](https://github.com/puutaro/yomel/blob/master/DEEPDIBE.md#3-option-and-argument-value-modifiers-with-pascalcase-suffixes)    
- Add Log (`Total-cmd`, `Cmd`) with suffix description .  
- Add [`title`](https://github.com/puutaro/yomel/blob/master/DEEPDIBE.md#title-pipeline_title) parameter.  
- Add [`--no-live-stdout`](https://github.com/puutaro/yomel/blob/master/DEEPDIBE.md#--no-live-stdout), and [`--no-live-stderr`](https://github.com/puutaro/yomel/blob/master/DEEPDIBE.md#--no-live-stderr) option.   
- Enable to specify hyphen prefix after `--val`, and `--arg`.  
- Enable to specify `title` and `stage` string prefix after `stage`, `title`, `--opt`, `--lop`, `--val`, and `--arg`.(ref: [DEEPDIVE](https://github.com/puutaro/yomel/blob/master/DEEPDIBE.md))  
- Add `--opt` and `--lopt` not blank validation. (ref: [DEEPDIVE](https://github.com/puutaro/yomel/blob/master/DEEPDIBE.md))   
- Reflect last pipline cmd exit signal to yomel exit signal.  
- Ajust newline for each section end.
